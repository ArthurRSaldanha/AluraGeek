# AluraGeek
Projeto criado para entrega do Challenge do programa Oracle One Next Generation em conjunto com a Alura

Através deste projeto pude concretizar meus conhecimentos sobre o uso de API's e lidar com os possíveis erros e interações de usuário com a mesma.

Neste projeto, fiz uso de uma Mock API, que é uma API de uso local, geralmente usada a fim de testes em grandes projetos. Para utilizá-la precisei me familiarizar com o uso de do npm e também com o json-server, pois para criar um link utilizável para o Fetch() da API, é preciso usar o comando "json-server --watch db.json" no terminal

Também aprendi o uso de um banco de dados fake, criado em JSON e interagir com ele através das requisições GET, POST e DELETE.

Este projeto com marcado por desafios, mas no fim me foi possível concluí-lo e aprender novas tecnologias e adquirir novos conhecimentos, me tornando um melhor programador e resolutor de problemas.
